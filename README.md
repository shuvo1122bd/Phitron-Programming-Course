A collection of my programming practice, assignments, and problem-solving solutions completed while following the **Phitron Programming Course**. This repository documents my journey of learning **C** and **C++**, starting from programming fundamentals to basic data structures and algorithms.

* Improve problem-solving skills.
* Learn C and C++ from the basics.

## 💻 How to Run

### Compile a C program

```bash
gcc filename.c -o output
./output
```

### Compile a C++ program

```bash
g++ filename.cpp -o output
./output
```

Or you can use any IDE such as:

* Visual Studio Code
* Code::Blocks
* Dev-C++
* CLion
